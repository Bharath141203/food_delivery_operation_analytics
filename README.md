# food_delivery_operation_analytics
# 🍽️ Food Delivery Analytics

## 📌 Project Overview

This project is an end-to-end Food Delivery Analytics solution developed using Python, SQL, and Power BI.

The objective of this project is to analyze food delivery operations, customer behavior, menu performance, delivery partner efficiency, delivery delays, and peak-hour trends to generate meaningful business insights.

---

## 🎯 Project Objectives

- Analyze overall sales and order performance
- Understand customer purchasing behavior
- Identify top-performing menu items
- Analyze menu category performance
- Evaluate delivery partner performance
- Identify delivery delays and their major factors
- Analyze peak-hour ordering patterns
- Compare distance and delivery delays
- Generate actionable business recommendations

- Identified high-performing menu items based on order volume, revenue, and ratings.
- Analyzed delivery delay patterns across delivery areas.
